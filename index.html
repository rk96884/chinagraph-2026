Featured Work

Football Tournament Manager

A modern full-stack application for organising grassroots football tournaments, built with React and ASP.NET Core.

React ASP.NET Core Entity Framework Core SQLite

The Challenge

Grassroots football tournaments are often managed using spreadsheets, paper schedules or multiple disconnected tools. This makes it difficult to organise teams, fixtures and league tables efficiently, particularly when results need to be updated throughout the day.

My Approach

I designed and developed a responsive full-stack application using React, ASP.NET Core and Entity Framework Core. The application provides an intuitive interface for managing tournaments while exposing a RESTful API to handle teams, fixtures and results.

Outcome

The finished application enables organisers to manage tournaments from a single interface, reducing manual administration while providing a clean, responsive experience across desktop and mobile devices.

Highlights

  • Responsive user interface
  • Real-time tournament management
  • RESTful ASP architecture
  • Entity Framework Core data layer
  • SQLite database
  • GitHub deployment workflow
