# CHINAGRAPH // 2026

> **A portfolio 25 years in the making.**

A modern, accessibility-first portfolio website showcasing over 25 years of front-end development, from the early days of handcrafted HTML and graphic design through to modern responsive web applications.

---

## Project Vision

CHINAGRAPH // 2026 is more than a portfolio.

It tells the story of continuous learning, technical growth and a passion for building accessible, user-centred digital experiences.

Rather than simply listing projects, the site demonstrates the evolution of front-end development through real commercial work, personal projects and modern engineering practices.

---

## Features

- Responsive, mobile-first design
- Accessibility-first (WCAG 2.2 AA)
- Semantic HTML5
- Modern CSS architecture
- Vanilla JavaScript
- Dark & Light mode
- Interactive career timeline
- Portfolio case studies
- Football Tournament Manager showcase
- Downloadable CV

## Accessibility

Accessibility is a core feature of this project.

Goals include:

- WCAG 2.2 AA compliance
- Keyboard navigation
- Visible focus states
- Semantic HTML
- High colour contrast
- Screen reader support
- Reduced motion support
